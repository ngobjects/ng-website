# engifer logo

*Engifer* is Icelandic for ginger. The mark is a hand of ginger root with a green shoot, and the wordmark is set in Atkinson Hyperlegible Bold (the site's typeface) with the text converted to outlines, so the files don't depend on the font being installed.

The `ng` inside the name is coloured to keep the old ng-objects name visible in the new one.

## Files

| File | Use |
| --- | --- |
| `engifer-mark.svg` | The mark on its own, in colour. Works on light and dark backgrounds. |
| `engifer-mark-mono-dark.svg` | Single-colour outline mark for light backgrounds. |
| `engifer-mark-mono-light.svg` | Single-colour outline mark for dark backgrounds. |
| `engifer-logo.svg` | Mark and wordmark for light backgrounds. |
| `engifer-logo-on-dark.svg` | Mark and wordmark for dark backgrounds, as in the site header. |
| `engifer-logo-mono-dark.svg` | Single-colour logo for light backgrounds. |
| `engifer-logo-mono-light.svg` | Single-colour logo for dark backgrounds. |

`png/` holds rendered versions with transparent backgrounds: the mark at 16 to 1024 pixels, the mono marks at 512, every logo at 1200 pixels wide, and `engifer-social-1200x630.png`, a preview card for link sharing.

The full palettes, and earlier ones, are in the brand manual at `brand/index.html`.

The site's favicon (`src/main/resources/public/engifer.svg`) is the same mark without the padding, so it fills the small space it gets.
