# Social images

From the articulated root (variant 5 in `src/main/resources/public/logo-explorations/roots.html`).

| File | Use |
| --- | --- |
| `png/engifer-avatar-1024.png` | GitHub avatar, Facebook profile picture (on the hero's emerald) |
| `png/engifer-avatar-light-1024.png` | The same on a light background |
| `png/facebook-cover-1640x856.png` | Facebook cover. Content sits in the middle: desktop shows the middle 1640×624, phones a narrower centre |

Avatars are cropped to a circle by both sites, so the mark stays inside it.

Regenerate with `python make_social.py` (needs fonttools and brotli, and Google Chrome for rendering).
